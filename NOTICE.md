# Authorship, rights and evidence boundaries

Agent Workflow Kit, © 2026 Дмитрий Лукашов (Dmitry Lukashov).

The meeting-note span checker, reviewed-register export, bilingual process
runbook, documentation and invented teaching inputs were prepared for this
standalone public module with AI assistance. The install/uninstall helpers
adapt the same author's public MIT helpers from
[CRM RevOps Kit v0.1.0](https://github.com/ilookatshow-gif/crm-revops-kit/tree/v0.1.0).
Their authorship and MIT rights are retained. No private Lookatshow core,
company workspace, real transcript, customer note, contact list, proprietary
workflow or third-party skill collection was copied into this package.

The runtime uses Python's standard library. It reads only the explicitly
supplied local JSON files and can write a local CSV. It does not call a model,
fetch recordings, authenticate a person, send messages or create live tasks.
A source-span match is a text match; it does not establish meaning, commitment,
owner agreement, deadline agreement, completeness, task completion or payment.
File hashes identify exact input versions. A reviewer ID and review date are
supplied declarations, not authenticated evidence that a review happened.

The MIT license covers the distributed package files and grants no rights to a
user's notes, recordings, correspondence or review records. The bundled source,
candidates, decisions and outputs are invented teaching examples, not captured
model responses, client cases or business results.

Learning and implementation are optional separate services. No subscription,
registration, payment or attribution inside generated JSON/CSV is a condition
of the MIT license. Normal outputs have no advertising inserts. Explicit
onboarding shows the author's links once. No telemetry is built into the CLI.
